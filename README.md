# Thailand Government Lottery VIP Portal

A complete, single-file React web application for the Thailand Government Lottery VIP Portal with a premium dark royal-emerald and gold UI theme.

## Quick Start (Local Setup)
1. Extract this ZIP archive.
2. Open terminal in the extracted folder.
3. Run `npm install` to install dependencies.
4. Run `npm run dev` to start the development server.

## Deploy to Vercel or Netlify
- Push this folder to a GitHub repository.
- Import the repo into Vercel or Netlify for instant free live hosting.
